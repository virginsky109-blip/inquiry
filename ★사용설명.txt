      포워딩 견적 자동생성 프로그램  —  사용설명
════════════════════════════════════════════════════════

■ 사용법은 두 가지 (아무거나)
  ┌───────────────────────────────────────────────┐
  │ [방법 A] 클릭식 프로그램  ← 추천, 간편          │
  │   "견적프로그램.bat" 더블클릭                    │
  │   → 창이 뜨면 수출/수입·구간·컨테이너·대수·     │
  │     상차지 선택 후 [견적서 생성] 버튼            │
  │   → 견적서 1장이 바로 생성됩니다.               │
  │                                                 │
  │ [방법 B] 엑셀 일괄 처리  ← 여러 건 한 번에      │
  │   화주요청서.xlsx 에 여러 줄 입력 →             │
  │   "2_견적생성.bat" → 건별로 한꺼번에 생성       │
  └───────────────────────────────────────────────┘
  ※ 둘 다 같은 운임표(운임표.xlsx)를 사용합니다.
  ※ 처음 1회 "1_초기설정.bat" 을 먼저 실행해야 합니다.


■ 무엇을 하나요?
  화주요청서(구간·사이즈·대수)를 읽어서, 운임표의 항목별 단가로
  무브양식 형태의 견적서를 '건별 엑셀 파일'로 자동 저장합니다.

  [항상 지키는 4단계 — 순서 고정]
   1. 요청서에서 출발·도착·사이즈·대수 읽기
   2. 운임표에서 같은 구간의 항목별 단가 찾기
   3. 금액 = 단가 × 수량
        · CNTR 단위 항목  → × 대수
        · BL / 문서 항목   → × 1
        · USD 단가 항목    → × 환율(원화 환산)
   4. 무브양식 빈칸을 채워 건별 견적서(.xlsx)로 저장


■ 처음 한 번 (준비)
  1) "1_초기설정.bat" 더블클릭
     → 운임표.xlsx, 화주요청서.xlsx 가 만들어집니다.
     (이미 있으면 새로 덮어씁니다. 실제 데이터를 넣어둔 뒤에는
      다시 누르지 마세요 — 덮어써집니다.)


■ 매번 견적 뽑을 때
  1) "화주요청서.xlsx" 를 열어 견적낼 건을 입력
        화주명 / 출발항 / 도착항 / 사이즈(20FT·40FT) / 대수
     - 여러 줄 = 여러 건 (한 번에 다 처리됩니다)
     - 출발항·도착항 이름은 운임표의 '구간정보' 시트와 똑같이!
        (예: 부산, 인천, 평택 / 첸나이, 람차방)
  2) 저장 후 "2_견적생성.bat" 더블클릭
  3) "견적서_출력" 폴더에 건별 견적서가 저장되고 자동으로 열립니다.


■ 운임(단가)이 바뀌면
  "운임표.xlsx" 의 [운임DB] 시트에서 숫자만 고치면 됩니다.
   - 20FT_단가 / 40FT_단가 : 요율 숫자
   - 20FT_통화 / 40FT_통화 : KRW 또는 USD
   - 20FT_UOM  / 40FT_UOM  : CNTR(대수로 곱함) 또는 BL(1로 고정)
   - 비고 : 견적서 REMARK 칸에 그대로 표시
   [구간정보] 시트에서 환율(적용환율)·제목·운송구간 문구를 관리합니다.

  ▶ 새 구간을 추가하려면
     [운임DB]에 그 구간의 항목들을 아래로 추가하고,
     [구간정보]에도 그 구간의 환율/제목/운송구간 한 줄을 추가하세요.


■ 파일 구성  (★클릭할 파일은 .bat 3개 뿐★)
   견적프로그램.bat    … [방법 A] 클릭식 견적 프로그램
   1_초기설정.bat      … 운임표·요청서 생성 (처음 1회)
   2_견적생성.bat      … [방법 B] 엑셀 일괄 견적생성
   운임표.xlsx         … 구간별 항목 단가 + 환율 + 구간정보 (관리 대상)
   화주요청서.xlsx     … [방법 B] 견적 요청 입력
   견적서_출력\        … 완성된 견적서가 쌓이는 폴더
   setup.ps1 / batch_quote.ps1 / quote_app.ps1
                       … 실제 동작 엔진 (건드리지 마세요)


■ 클릭식 프로그램(방법 A) 화면 항목
   수출/수입  →  출발국가 → 출발항  →  도착국가 → 도착항
   →  컨테이너 타입(20FT/40FT/40HC/20DG/40DG)  →  대수
   →  상차지(수입이면 하차지)  →  화주명  →  [견적서 생성]

   · 드롭다운 목록은 운임표(구간정보)에서 자동으로 만들어집니다.
     구간/국가/항구/상차지를 늘리려면 운임표에 줄만 추가하면 됩니다.
   · 40HC 는 40FT 요율로 자동 계산됩니다.
   · 수입 구간과 20DG/40DG 요율은 아직 데이터가 없어,
     운임표.xlsx 에 해당 요율을 추가하면 즉시 반영됩니다.


■ 참고
  · Excel 이 설치돼 있어야 합니다 (별도 설치 불필요).
  · 요청서의 구간이 운임표에 없으면 그 건만 건너뛰고 나머지는 처리됩니다.
    (실행 창 마지막에 '미매칭' 으로 표시)
